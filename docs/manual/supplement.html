1 > NOTES

This supplement describes what the XT firmware 1.2.13 (formerly OE02-Samples+) adds to the LXR-02 and its manual.

It contains the modifications of OpenElixir-02 1.2 (Moritz Waser), marked OE.

1.1. About the tables

As in the manual: display name (three letters), full name, function. The edit view (press the encoder) shows the full name and the value.

Buttons by their label below the step button, e.g. SHIFT + FX (step 15).

1.2. What is stored where

Global: kept only after SAVE → Global. All new settings with their storage: appendix A.

1.3. Installation

  1. LXR_XT_V1.2.13.img into the top folder of the card; delete all other LXR*.img there.
  2. Switch on with the encoder button held until “LXR Updater” appears.
  3. “Update OK!”, then delete the image.
  4. The update erases the samples: leave SAMPLES on the card, the next start imports them again.

After switching off, wait ≈ 10 s.

1.4. Compatibility

Kits and patterns of the original firmware and of OpenElixir-02 load; new settings start with default values.

New kits also load in older firmwares (without the additions); voices with a sample or wave stay silent there, new engines play the default engine.

Going back: install the image of OpenElixir-02 or Erica Synths the same way.

2.2. Sample import

At start the LXR compares the folders with the internal flash (names and sizes) and imports again on changes. The samples also play without a card.

Rule
FormatWAV, 16-bit PCM, mono or stereo (mixed to mono), any sample rate
Names8.3 format (01KICK.WAV); the slots S1 … S31 follow the order of the names, numbers by value (2KICK before 10KICK)
Countup to 31 samples (both folders together) and 8 waves
Lengthabout 5.9 s mono in total at 44.1 kHz (11.9 s at 22.05 kHz); a stereo file counts at half its size
Ignorednames starting with . or _

A file replaced by one with the same name and size is not imported again.

Start screen

S:12 W:3 T:2 = stored samples, waves and wavetables.
Below: Used 4.2/5.9s = used and available sample time.

2.3. Experimental: 1.5 MB sample memory

The chip reports 1 MB of flash but usually has more.
With BIGFLASH in the SAMPLES folder: 17.8 s instead of 5.9 s.

  • Not guaranteed (ST). Every sample is verified; on an error “Big flash failed / using 512K” and import into the normal memory.
  • If the start hangs permanently: remove BIGFLASH or start without a card. Firmware and bootloader are not affected.

2.4. Kits

Additionally in the kit: per voice the engine OE, start and length of the sample, choke group, sends; per kit the order of the FX slots and FX3.

3 > Voices

3.1. Engines per voice OE

Each of the 6 slots selects its engine: drum, snare, cymbal, hi-hat.
New: modal, fm2 and wavetable (3.12–3.14).
SHIFT + KIT: engine menu of the active voice. In the kit.

3.2. Oscillator sources

Main oscillator: built-in waveforms, samples (own pitch, once or as a loop) or waves (single cycles, follow the note).

3.3. Oscillator page (OSC)

DisplayNameDescription

FM page of the drum engine: samples and waves also as FM source.

3.4. Samples and loops

  • SAMPLES: once per trigger; the AEG decay can end it earlier.
  • SAMPLES/LOOPS: looped from sta to len. Each trigger restarts at sta; in between the loop runs until the decay fades it out (dec = 127: until the next trigger).
  • Sequencer stop fades out all loops.

3.5. Waves

  • Up to 8 WAV files in SAMPLES/WAVES, one cycle each: W1 … W8 (W1 = first name). Stereo: left channel.
  • Against clicks: start and end at a zero crossing, rising at both ends, no DC offset.

3.6. Modulated sample selection

An LFO or velocity with target wav selects among the following samples (or waves):

  • Range: from the selected sample, as many more as LFO mod / velocity amt (S5, amount 4 = S5 … S9). Chosen at the trigger.
  • Velocity layers: soft to loud versions, named in sequence, select the softest, amt = layers − 1.
  • Round robin: LFO dst = wav, LFO waveform cyc: one sample per trigger.
  • Random: LFO waveform rnd, rate faster than the triggers.
  • Only the target wav selects samples, not fwv / cwv.

3.7. Amplitude envelope (AEG)

  • Sends: after pan, after the fader (unless pre is on, chapter 6.3). Send/return: slot at 100 % wet.

One-shots: one cycle per trigger (voice of rtg, else its own), then hold. Length: frq / snc.

3.9. Track 7

Tracks 6 and 7 play one voice. Track 7 has its own values for decay, wav, coa (±24 semitones to track 6), sna, snb, pan and its own LFO. Edit view: “Trk7 …”, =t6 = as track 6. Sends and pan: those of the track that triggered last.

3.10. LFO 2 (test)

  • Second LFO screen, press LFO again: LFO 2 of the voice, same parameters.
  • Track 7: the LFO page is its own LFO; acts while track 7 plays.
  • Stored in the kit, not morphed.

3.11. Random voice

  • SHIFT + encoder click on a voice page (OSC, AEG, MOD, FM, transient, filter; not in the edit view): new random variant of the active voice.
  • Amount: rnd (PERF, default 32). Switching values change with this probability.
  • Kept: volume, pan, out, sends, LFO, choke, engine.
  • Undo: reload the voice.

3.12. Engine modal (test)

Physical modelling: 6 resonators ring in the modes of a struck body. Drum pages:

DisplayNameDescription
dmpDampingMOD: decay time, 30 ms … 6 s
inhInharmonicMOD: stiffness, spreads the upper modes
posStrike pos.MOD: edge (0) … centre (127)
hrdHardnessFM: soft … hard mallet
matMaterialFM: 0 = metal … 127 = wood (highs decay faster)
mdlModelFM: mem membrane, bar bar, str string, bel bell, plt plate, gls glass
excExciterFM: mal mallet, nse noise

The transient sample excites in addition. A new strike adds to the ringing. New voice: decay 110.

3.13. Engine fm2 (test)

2-operator FM: sine carrier, sine modulator with its own index decay. FM page:

DisplayNameDescription
ratRatiomodulator : carrier, .50 … 11 (odd values = metallic)
idxFM indexmodulation depth at the strike
idcIndex decay5 ms … 4 s

MOD page: pitch EG as on the drum.

3.14. Engine wavetable (test)

Scans a set of waves (frames). FM page:

DisplayNameDescription
setTable setbas sine › triangle › square › saw, usr from the waves, all = both, t1 … t4 from SAMPLES/TABLES. Edit view: file name or none>bas
posWave pos.0 = first frame … 127 = last
swpPos. sweepthe pitch EG pushes the position up at the strike, back to pos
scnScan modesmo smooth, stp stepped, pp back and forth, pps back and forth stepped
  • Position = pos + swp × pitch EG (MOD page: decay, slope; amount 0 = no pitch change) + LFO/automation on pos. Not the amp envelope.

Own sets: SAMPLES/TABLES

  • Up to 4 WAV files (t1 = first name): 16/24 bit or float, mono/stereo (left).
  • Cycle length: from the clm chunk (Serum, Vital), else 2048 or 256 (WaveEdit).
  • Max. 64 frames; fewer: in-between waves are added. 64 frames ≈ 0.9 s of sample memory, after the samples.

4 > Sequencer

4.1. Lock trigger: velocity 0

Velocity 0: no trigger, no MIDI note; P1/P2 still act (“trigless lock”). SHIFT + encoder click on the automation page clears both locks.

4.2. Step flam: ratchets and roll locks

flmEffect (after x2 … x8)
x12, x2412 / 24 repeats in the step
x4+, x4-4 repeats, velocity rising / falling (25 … 100 %)
1/8 1/4 1/2 1/1roll lock: a repeat every 2, 4, 8, 16 steps up to the next active step

4.3. Step accent and octave

  • acc (first step page, after prb): accent on/off for the step, stored in the pattern.
  • aca (CONFIG, second page, global): amount +0.1 … +6 dB, default 64 ≈ +3.5 dB.
  • Acts like the voice's fader, only for this trigger.
  • oct (after sft): random octave instead of the voice's (3.3): vce (as the voice), off, ±1, ±2, ±3, +1, −1.

4.4. Instant pattern switch

ips on (CONFIG, second page): a pattern chosen by hand starts at the next step at the same position. Chains and songs still switch at the end.

4.5. Step grid per track

SHIFT + LAST STEP: [16] 1/16 1 = length, grid, step length (1/16 = 1). Press the encoder: edit the grid. ALL mode (LAST STEP again): all tracks.

GridStep length · steps per bar
1/4 · 1/4T · 1/84 · 8/3 · 2 — 4 · 6 · 8
1/16. · 1/8T · 5/646/4 · 4/3 · 5/4 — 10⅔ · 12 · 12⅘
1/161 — 16 (default)
1/32. · 1/16T3/4 · 2/3 — 21⅓ · 24

  • Each track loops in its length (polymeter); the pattern ends after the longest.
  • rol and flams count in the track's steps; live recording in 1/16.
  • Stored in the pattern.

4.6. Trigger tracks

LAST STEP page, each encoder click moves on: length › Start › grid › Trg [OFF] › target >[T3] › LFO>[T3] › NXT/NOW. Taken targets are skipped.

TrgEach active step …
RSTsets the target to step 1 (plays at once)
MUTmutes the target for the step's duration
CLKadvances the target one step (only with these pulses)

All velocities count; velocity 0 does not sound itself. A track is the target of one source at most.

4.7. LFO start

LFO>[T3]: each start of the LFO waveform of this track's voice (new cycle, rtg, one-shot) starts track 3 at step 1: NXT at the next step in the target's grid, NOW at once.

  • The target plays to its last step and waits; silent until the first start.
  • With snc in time; free running it drifts (generative).
  • Trigger and LFO target possible at the same time.

4.8. Start, loop, gates, copying (test)

  • Start (LAST STEP page): the track plays start … last step; RST and LFO start begin there.
  • Loop per track: SHIFT + PROJECT on/off for the active track. Hold a step, press a second (also on another page); second before first = backwards. A single press: off. Ends with a pattern change.
  • Gate: hold a step, press a later one: the first holds to the end of the second (AEG at full level, MIDI note off at the end). First step off: gate gone.
  • Copy: hold COPY, select steps, release; the next step press pastes them with their distances from there (up to the track length). Steps in between stay.
  • SHIFT + MORPH: duplicate the range start … last step behind it (length × 2, max. 64).

5.2. WAV recorder

Records St1 (after FX3, DJ filter, limiter) as WAV to the card: REC/REC001.WAV …, 16-bit stereo, 44.1 kHz.

DisplayNameDescription
recRecord WAVlength: x1, x2, x4 passes of the longest track, end until stop. Display arm / rec
rstRec startply with PLAY, pat at the next pattern start (also with the sequencer running)
  • Encoder click in the edit view: arm (creates the file) / cancel / end the recording.
  • Ends after the passes, at STOP or on a click: “Saved REC003 1:32”.
  • rec and rst are global and stay set after the recording.
  • Slow card: dropouts are counted (“2 gaps”). Avoid loading/saving while recording.

5.3. Kit morph

  • MIDI CC 1 (global channel) sets mrp.
  • mrp 0 → 127: from the active kit to the morph kit. Edit view + SHIFT: Morph> and target value; SHIFT + encoder click: parameter does not morph.
  • mrv (CONFIG, page 2): morph per voice; edit view: voice buttons.

5.4. Voice morph

DisplayNameDescription
vmvVoicespair source > target: OFF, 1>2 … 6>5
vmoAmount0 = source, 127 = values of the target
vswSwitchfrom this vmo on: switching values (waveform, filter type) of the target

Only vsw is stored (global).

5.5. Cue on St2

  • SHIFT + step 1–7 (on any page): pre-listen to a track, LED blinks.
  • Pre-fader, also muted tracks. St2 becomes the cue bus automatically.
  • cmx: cue ↔ main on St2, cvl: level.
  • Needs cables in St1 (L and R); otherwise St1 plays on the St2 jacks.

6.4. FX knobs

SHIFT + knob 1 / 2: input level FX1 / FX2 (−∞ … +12 dB, global); 3 / 4: mix. Not on LOAD/SAVE.

6.5. Master bus FX3

Third slot at the end of St1: after FX1/FX2, before DJ filter and limiter. Saturation (S), compressor (C), EQ (E) in the order ord. In the kit.

Split: only the band above the crossover is saturated / compressed. csm = sc: the upper band only controls, everything is compressed.
